<h1 align="center">ficelle-site</h1>

<p align="center">The website of <a href="https://github.com/Synaelle/ficelle">Ficelle</a>.</p>

## Development

```bash
pnpm install
pnpm dev
```

The page opens at http://localhost:1430/site/. Add `?os=windows`, `mac`, `linux`, `android`, `ios` or `none` to the address to see it as on another system.

`pnpm build` writes the site to `dist/`.
